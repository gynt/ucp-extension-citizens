# Citizens

A lakosok viselkedését szabályozza.

### Egyes lakosok megjelenésének tiltása

Részegek, tyúkok, anyák, gyerekek és az udvari bolond: kapcsold ki a megjelenésüket, ha zavarnak!

### Később: tűzoltási sorrend szabályozása

A tűzoltók néha jelentéktelen épületeket részesítenek előnyben a fontosabbakkal szemben. Ennek szabályozása jövőbeli terv.

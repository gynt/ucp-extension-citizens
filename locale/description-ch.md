# Citizens

控制居民行为。

### 禁止生成部分居民

醉汉、鸡、母亲、儿童和弄臣：如果觉得他们碍事，可以禁止生成这些单位！

### 未来计划：控制消防队的灭火优先级

消防人员有时会优先处理不重要的建筑，而忽略更重要的建筑。控制这一优先级是未来计划。
